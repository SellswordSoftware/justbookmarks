 High-value additions:

  - Multi-select and bulk actions: move, delete, tag, archive, fetch favicons, normalize titles.
  - Import/export beyond Netscape HTML: JSON backup format, Chrome/Firefox direct import, maybe CSV export.
  - Undo/redo: especially for move, delete, rename, and bulk edits.
  - Persistent UI state: remember expanded folders, selected node, pane widths, window size, last-opened file.
  - Better move/reorder UX: drop targets between items, keyboard move commands, cut/copy/paste for bookmarks.
  - Duplicate detection: find duplicate URLs, same-title duplicates, and near-duplicates.
  - Bookmark validation: detect dead links, redirects, timeouts, and optionally flag stale bookmarks.
  - Tagging or labels: lightweight classification without forcing everything into folders.
  - Sort/cleanup tools: sort folders alphabetically, domain grouping, dedupe, strip tracking params.
  - Rich search/filtering: by title, URL, notes, tag, folder, broken links, missing favicon, date added.
  - Global create flow: add bookmark/folder from anywhere with target-folder picker.
  - Safer save model: autosave toggle, dirty-state indicator, explicit backup/restore points.
  - Better metadata editing: editable dates, notes preview, favicon override/remove, open graph title fetch.
  - Keyboard-first workflow: command palette, quick search, rename shortcut, move shortcut.
  - Drag in bookmark files directly onto the app window to open them
